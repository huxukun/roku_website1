| 原则 | 说明 | 对应目标 |

## 2. 色彩

### 2.1 品牌色

| 令牌 | 色值 | 用途 | 对比度（白底） |
|---|---|---|---|
| `--brand-600` | `#1F6FEB` | 主按钮、选中态、链接、进度 | 4.63:1 ✅ |
| `--brand-700` | `#1457C4` | 按下态、hover 深色 | 6.2:1 ✅ |
| `--brand-900` | `#0B3D91` | 深色标题、强调文字 | 10.0:1 ✅ |
| `--brand-50` | `#EAF2FF` | 选中底色、标签底 | — |
| `--brand-100` | `#D6E6FF` | 边框、进度槽 | — |

> 南邮蓝以 `#1F6FEB` 为基准。**正文不使用 brand-600 以下的浅蓝**，`--brand-100` 仅用于背景与描边。

### 2.2 语义色

| 令牌 | 色值 | 文本场景 | 背景场景 |
|---|---|---|---|
| `--success` | `#1A7F37` | 成功文字（5.09:1） | `#E9F7EE` |
| `--warning` | `#B54708` | 警告文字（5.3:1） | `#FFF4E5` |
| `--danger` | `#D92D20` | 错误文字（4.82:1） | `#FEECEB` |
| `--info` | `#1F6FEB` | 提示文字 | `#EAF2FF` |

> 语义色**不可只靠颜色区分**：错误同时给图标 + 文案，成功同时给勾选图标。

### 2.3 中性色

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--ink-900` | `#0F172A` | 一级标题、关键数字 |
| `--ink-700` | `#334155` | 正文 |
| `--ink-500` | `#64748B` | 次要文字、说明（4.74:1 ✅） |
| `--ink-300` | `#94A3B8` | 占位文字（仅 ≥16px 或非关键） |
| `--line` | `#E2E8F0` | 分割线、卡片描边 |
| `--line-strong` | `#CBD5E1` | 输入框描边 |
| `--surface` | `#FFFFFF` | 卡片、弹层 |
| `--bg` | `#F5F7FB` | 页面底色 |
| `--bg-sunken` | `#EDF1F7` | 骨架屏底色 |

### 2.4 使用规则

- 正文对比度 ≥ **4.5:1**，大字（≥18.66px 粗体 / ≥24px）≥ **3:1**。
- 品牌色不用于大面积正文；主按钮文字用白色（`#FFFFFF` on `#1F6FEB` = 4.63:1）。
- 图表配色顺序：`#1F6FEB` → `#12B76A` → `#F79009` → `#7A5AF8` → `#EE46BC`，配合纹理/标签区分。
- 深色模式本期**不做**，避免与课程评审范围脱节。

## 3. 字体与排版

### 3.1 字族

```css
font-family: "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei",
             "Noto Sans SC", system-ui, -apple-system, sans-serif;
font-variant-numeric: tabular-nums;  /* 成绩、学分、倒计时对齐 */
```

### 3.2 字号阶梯（移动端）

| 级别 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 34 / 42 | 700 | 首页问候、GPA 大数字 |
| `h1` | 28 / 36 | 700 | 页面主标题 |
| `h2` | 22 / 30 | 600 | 区块标题 |
| `h3` | 18 / 26 | 600 | 卡片标题 |
| `body` | 16 / 26 | 400 | 正文、列表主文案 |
| `body-sm` | 14 / 22 | 400 | 辅助说明 |
| `caption` | 12 / 18 | 400 | 时间戳、标签、脚注 |

- 桌面端（≥1024px）整体放大 1 档，最大正文不超过 18px。
- 中西混排不加空格；数字与单位之间不留空格（如 `3.8`、`120 分钟`）。
- 单行文本超过 2 行需截断（`-webkit-line-clamp: 2`），完整内容放详情页。

## 4. 栅格与间距

### 4.1 断点

| 断点 | 视口 | 布局 | 边距 | 栏数 / 槽宽 |
|---|---|---|---|---|
| `sm` | 375–767 | 单列 | 16px | 4 栏 / 8px |
| `md` | 768–1023 | 双列卡片 | 24px | 8 栏 / 16px |
| `lg` | ≥1024（作品集 1440 基准） | 内容居中，最大 1200px | 32px | 12 栏 / 24px |

- 原型以 375×812 画布设计；`md` 以上仅做「不破版」适配，不新增信息。
- 底部 Tab Bar 高 **56px + 安全区**；顶部 AppBar 高 **56px**。
- 页面左右安全边距：移动 16px；卡片内边距 16px；卡片间距 12px。

### 4.2 间距刻度（4px 基数）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`

- 组件内部：8/12；组件之间：12/16；区块之间：24/32。
- 点击热区最小 **44×44px**（视觉可小于热区，但热区不可小于）。
- 圆角：小控件 8px，卡片 12px，弹层/大卡 16px，胶囊 999px。
- 阴影：`0 1px 2px rgba(15,23,42,.06)`（静置）、`0 12px 32px -12px rgba(15,23,42,.24)`（浮层）。

## 5. 组件规范

### 5.1 导航

| 组件 | 规格 |
|---|---|
| AppBar | 高 56；左返回（44 热区）或页面标题；右操作图标 ≤2 个 |
| TabBar | 5 项：今日 / 课表 / 成绩 / 选课 / 我的；图标 24 + 文字 10；选中 brand-600，未选中 ink-500 |
| 分段控件 `Segmented` | 高 36，胶囊底 `--bg-sunken`，选中白底 + 阴影 |
| 抽屉 `BottomSheet` | 圆角 16 只在上方，最大高 80vh，带 4×36 拖拽条，遮罩 `rgba(15,23,42,.4)` |

### 5.2 按钮

| 类型 | 规格 |
|---|---|
| Primary | 高 48（列表内 40），`--brand-600` 底 + 白字，圆角 12；按下 `--brand-700`；禁用 `#E2E8F0` 底 + `#94A3B8` 字 |
| Secondary | 白底 + `--brand-600` 描边 1.5px + 品牌色字 |
| Ghost | 无底无描边，品牌色字，最小 44 热区 |
| Danger | `--danger` 底白字，仅用于不可逆操作，需二次确认 |

- 一屏最多 1 个 Primary；按钮文案用动词（「去评教」「重新登录」），不用「确定/提交」这类含糊词。

### 5.3 卡片与列表

- 卡片：白底、12px 圆角、1px `--line` 描边、无重阴影；整卡可点时有按下态（`scale .99` + 底色 `#FAFBFD`）。
- 列表项：高 56–72；左侧图标 40×40 圆角 10 品牌浅底；主文案 body，副文案 body-sm；右侧箭头或数值。
- 分组标题：caption + ink-500，左对齐，上间距 24 / 下间距 8。

### 5.4 表单

- 输入框高 48，圆角 12，描边 `--line-strong`；聚焦 2px `--brand-600` 外发光。
- 标签在输入框上方（body-sm，ink-700），不用 placeholder 代替标签。
- 错误态：`--danger` 描边 + 下方 12px 错误文案 + 图标；错误文案说明「怎么改」。

### 5.5 反馈组件

| 组件 | 规格 |
|---|---|
| Toast | 底部上方 24px，深色 `#0F172A` 90% 底，白字 14，2.4s 自动消失，`role="status"` |
| Skeleton | 底色 `--bg-sunken`，1.4s 呼吸，圆角与真实内容一致，**不整页转圈** |
| 进度/排队 | 线性进度 + 百分比 + 预计时间；排队时显示「第 N 位 / 预计 X 秒」 |
| 空状态 | 图形 96×96 + 主文案 16 + 解释 14 + 1 个主行动按钮 |
| 错误状态 | 图标 + 原因 + 解决建议 + 「重试」「帮助」两个出口 |

### 5.6 状态矩阵（必须覆盖的 5 类异常）

| 状态 | 触发 | 表现 | 出口 |
|---|---|---|---|
| 空状态 | 无成绩 / 无考试 / 无待办 | 插画 + 说明，不显示空白表格 | 「查看上学期」「刷新」 |
| 加载中 | 首次进入 / 切换筛选 | 骨架屏，保持结构不跳动 | — |
| 网络错误 | 请求失败 | 原因 + 重试 + 帮助 | 重试、去帮助 |
| 会话过期 | 长时间未操作 / 新标签 | 全屏或模态说明 + 倒计时 | 「一键重新登录」并**恢复原页与筛选** |
| 选课排队 | 高峰并发 | 排队位次、预计时间、取消 | 取消排队、失败重试 |

## 6. 图标与插画

- 线性图标，24×24，描边 1.5px，圆角端点；视觉风格统一，不混用面性与线性。
- 图标必须配文字标签（Tab Bar、功能入口），不单独承载语义。
- 空状态/错误插画用品牌蓝 + 中性色双色扁平风，单张 ≤40KB，SVG 优先。

## 7. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 状态切换、按钮反馈 | 150ms | `cubic-bezier(.2,.8,.2,1)` |
| 抽屉/弹层进出 | 240ms | 同上 |
| 页面切换 | 300ms | 同上 |
| 骨架呼吸 | 1400ms 循环 | `ease-in-out` |

- 只动 `transform` 与 `opacity`，不动布局属性。
- 尊重 `prefers-reduced-motion: reduce`：关闭位移与循环动画。
- 不做无意义的入场动画堆叠，动效服务于「发生了什么」。

## 8. 无障碍

- 语义标签：`header/nav/main/section/footer`、列表用 `ul/li`、按钮用 `button`。
- 键盘可达：焦点顺序与视觉顺序一致，焦点环 2px `--brand-600` + 2px 偏移。
- 图片/图标：装饰性 `aria-hidden="true"`，信息性提供 `alt`。
- 动态反馈：`aria-live="polite"`（排队、Toast），`aria-live="assertive"`（会话过期）。
- 表单：`label` 与控件 `for/id` 关联，错误用 `aria-describedby`。
- 触控：所有可点元素热区 ≥44×44，相邻热区间距 ≥8。

## 9. 文案规范

- 用「教务系统」而非「jwxt」；用「课表」而非「kbcx」；用「成绩查询」而非「cjcx」。
- 人称：对用户称「你」，不用「您」与「同学」混用。
- 错误文案结构：**发生了什么 + 为什么 + 怎么办**。
  - 反例：「系统升级维护中」。
  - 正例：「成绩暂时没加载出来。可能是网络波动，也可能是教务服务繁忙。可以重试，或稍后从『成绩』页再看。」
- 概念设计声明：页脚与「我的」页固定展示「课程作业 · 概念设计 · 非官方」。
- 数据说明：示意数据处标注「课程作业示意数据」。
