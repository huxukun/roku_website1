> 文件入口：`site/prototype/index.html`（线上路径 `/prototype/`；双击也可离线打开，无构建、无外部依赖）

## 1. 原型范围

移动端高保真可点击原型，375×812 为基准（≥600px 时显示为居中手机框）。覆盖 6 个核心页面与 5 类异常状态，所有数据来自 `mock.js`，接口形状由 `api.js` 模拟。

| 编号 | 页面 | 入口 | 主要目标 |
|---|---|---|---|
| P-01 | 首页 / 今日 | 底部 Tab「今日」 | G3 首屏即用、G4 三步内完成 |
| P-02 | 课表 | 底部 Tab「课表」/ 首页「完整课表」 | G3、G4 |
| P-03 | 成绩 | 底部 Tab「成绩」/ 首页「查成绩」 | G4（4 步 → 2 步） |
| P-04 | 选课 | 底部 Tab「选课」 | G1、G6（冲突、排队、失败） |
| P-05 | 考试 | 首页「查考试」/「下次考试」卡 | G4 |
| P-06 | 我的 / 登录 | 底部 Tab「我的」 | G1、G5（单点登录、会话续期） |

> 考试页是二级页面，从首页进入，顶部返回；底部 Tab 保持 5 项，不新增第 6 个入口。

## 2. 页面与交互清单

### P-01 首页 / 今日
- 问候 + 日期 + 第 12 周进度；今日课程时间轴（已结束 / 即将开始 / 待开始三态）。
- 待办：评教、教材预订、培养方案核对，点击复选框可勾选/取消。
- 快捷入口：查成绩、查考试、选课、评教。
- 最新成绩、下次考试倒计时卡。
- 页脚固定「课程作业 · 概念设计 · 非官方」。

### P-02 课表
- 周次切换（上一周 / 下一周 / 回到本周），周条 7 天，今天高亮、有课显示圆点。
- 日视图：按天列出课程，点击课程打开详情抽屉（时间、周次、教师、地点）。
- 周视图：周一至周五 × 8 节的课程网格，课程块可点击。
- 周末无课显示空状态。

### P-03 成绩
- 学期切换（4 个学期，含本学期「成绩未发布」空状态）。
- GPA 环、学期排名、学分、加权平均分。
- 筛选：全部 / 必修 / 选修 / 通识；筛选无结果显示专用空状态。
- 点击课程打开成绩详情（平时、期末、学分、绩点、等级）。

### P-04 选课
- 学分进度（已选 / 上限），已修 / 要求学分。
- 可选课程 / 已选课程切换；关键词搜索（课程名、教师）+ 类型筛选。
- 容量进度条与「已满」标记。
- **冲突**：点击冲突课程 → 冲突弹窗，说明与哪门课重叠，可跳课表。
- **排队**：正常选课 → 排队浮层（位次、进度、预计秒数），可取消；完成后成功 Toast。
- **失败重试**：`数据可视化` 在排队结束时名额被抢完 → 失败弹窗，可重试或加入候补。
- 退课需二次确认，退课后学分实时回退。

### P-05 考试
- 下一场考试倒计时（天 / 时 / 分）+ 考场座位。
- 列表：日期块、时间、考场、座位、距今天数。
- 日历：2026 年 12 月，考试日高亮，点击提示。
- 考前 3 天提醒说明。

### P-06 我的 / 登录
- 个人信息、统一身份认证状态（已登录、免 VPN、会话静默续期）。
- 设置列表：消息通知开关、数据来源与声明、帮助与反馈、关于本作品。
- 「模拟会话过期」入口。
- 退出登录二次确认 → 登录页。
- 登录页：学号 + 密码、统一身份认证按钮、免 VPN / 单点登录 / 会话续期标签、演示账号说明。
- 任意非空学号与密码即可登录（纯前端校验，不发请求）。

## 3. 异常状态与触发方式

在「我的 → 原型演示开关」中触发，供评审快速查看：

| 状态 | 触发 | 表现 | 恢复方式 |
|---|---|---|---|
| 加载中 | 加载中 · 骨架屏 | 当前页骨架屏，保持结构不跳动（2.8s） | 自动恢复 |
| 空状态 | 空状态 | 通用空状态卡 + 说明 + 刷新 | 「恢复正常」 |
| 网络错误 | 网络错误 | 原因 + 重试 + 帮助 | 重试 / 恢复正常 |
| 会话过期 | 会话过期 | 全屏弹窗、倒计时、一键重登 | 重登后回到原页且保留筛选 |
| 选课排队 | 选课排队 | 跳转选课并发起排队流程 | 完成 / 取消 |

页面内另有真实空状态：无课的一天、本学期无成绩、筛选无结果、未选课、无考试。

## 5. 交互与工程说明

- **无外部依赖**：图标为内联 SVG（Lucide 线性风格），字体使用系统字体，离线可打开。
- **状态集中管理**：`core.js` 中的 `state` 统一管理当前页、周次、学期、筛选、已选课程、异常状态标记。
- **数据与视图分离**：页面只读 `mock.js`，`api.js` 用 `wait()` 模拟延迟并保留真实接口签名，接入后端时替换实现即可。
- **导航一致性**：壳层（状态栏 / AppBar / 内容区 / TabBar）只渲染一次，切换页面只替换内容区；Tab 高亮由 `state.page` 统一决定，避免导航漂移。
- **无障碍**：语义化按钮、`aria-current`、`aria-live`、44px 热区、键盘 Enter/Space 可触发卡片、Esc 关闭浮层、焦点可见。
- **动效**：页面入场分段上浮 520ms；尊重 `prefers-reduced-motion`。
- **响应式**：≤360px 收紧字号；≥600px 显示手机框；≥768px 增加内容边距。

## 6. 与设计规范的对应

- 色彩、字号、间距、圆角、阴影、动效时长均使用 [设计规范.md](设计规范.md) §10 的令牌，未引入额外色值（课程分类色为 5 个受控色板）。
- 正文对比度 ≥4.5:1；主按钮白字 `#1F6FEB` 底 4.63:1。
- 所有可点元素热区 ≥44×44px；底部 Tab 高 62px + 安全区。
- 文案全中文语义命名，不出现 `kbcx` / `cjcx` 等拼音缩写。

## 7. 已知边界

- 数据均为示意数据，不代表真实教务记录；页面已标注「课程作业示意数据」。
- 选课排队与接口失败为前端模拟，计时 6 秒；真实环境需后端提供队列与幂等接口。
- 深色模式、消息中心、评教详情页不在本期范围，留待阶段三扩展。
